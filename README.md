# 斗地主 · DARCUO

简约深色局域网斗地主，配色参考 IntelliJ IDEA Darcula。三人浏览器联机，无需注册、无需数据库、无需 npm install。所有静态资源均在本地，不依赖外网。

## 房主：下载和启动

只有一台电脑需要运行服务。先安装 [Node.js 18 或更高版本](https://nodejs.org/)（推荐 22 / 24 LTS），然后下载本仓库：

```bash
git clone https://github.com/gjf1202/ddz_game.git
cd ddz_game
npm start
```

也可以在 GitHub 仓库页面点击 **Code → Download ZIP**，解压后双击 Windows 的 `启动游戏.cmd`。不需要执行 `npm install`。

1. 保持服务窗口运行，主机浏览器打开 `http://localhost:3000`。
2. 输入昵称，点击「创建房间」，记下页面显示的 **6 位房间号**。
3. 将终端显示的 **局域网地址**（例如 `http://192.168.1.20:3000`）和房间号发给朋友，也可以点击「复制邀请」。地址以你的电脑实际输出为准。
4. 三人分别点击「准备」，房主点击「开始游戏」。

> GitHub 页面用于获取源代码，不能直接作为联机游戏地址。需要先在电脑上运行 Node.js 服务。

## 朋友：如何加入房间

1. 手机、平板或电脑连接与房主电脑**同一个 Wi-Fi / 局域网**。
2. 在浏览器**地址栏**输入房主提供的局域网地址，例如 `http://192.168.1.20:3000`；不要在朋友设备上输入 `localhost` 或 `127.0.0.1`，它们指向朋友自己的设备。
3. 输入自己的昵称，点击「加入房间」，输入房主给出的 **6 位房间号**，再点击「加入牌桌」。如果打开的是带房间号的邀请链接，房间号会自动填好。
4. 点击「准备」，等待另外两人准备完毕并由房主开始。

**朋友不用下载代码，也不用安装 Node.js。** 房间人数上限为三人，房间号用于进入同一个牌桌。

朋友无需安装 Node.js，只需要浏览器。手机可用；横屏可获得更宽的手牌区域。只有一人时，可从首页进入「和机器人练一局」。机器人为基础陪练，不代表高水平 AI。

如果电脑有多块网卡，终端可能显示多个地址，请选择和朋友设备处于同一网段的地址。网页「复制邀请」会优先使用当前访问地址；本机 localhost 访问时使用首个局域网地址，必要时手动更换为正确网卡的地址。

## 网络连接

- 服务监听 `0.0.0.0:3000`。首次启动时，允许 Windows 防火墙的**专用网络**访问。
- 连不上时，确认设备在同一网络、关闭路由器的访客隔离 / AP 隔离，并检查主机防火墙是否允许 TCP 3000。可先在主机浏览器打开终端显示的局域网地址进行检查。
- 改端口：PowerShell 执行 `$env:PORT=3001; node server.mjs`，随后访问新端口。
- 关闭运行窗口或按 Ctrl+C 停止服务。保持电脑唤醒，其他玩家才能持续连接。
- 面向可信局域网，不要将端口映射到公网。房间号用于找房间；没有账号系统或加密传输。

## 玩法

### 1. 发牌和叫地主

一副牌共 54 张，每人 17 张，剩下 3 张作为底牌。依次选择「不叫」或叫 1 / 2 / 3 分，叫分必须高于当前分数。叫到 3 分立即结束叫分，否则三人叫分后由最高分者成为地主；全员不叫则重新发牌。地主获得底牌，共 20 张，由地主先出。

### 2. 出牌与获胜

地主单独一方，另外两位农民共同一方。地主先出完手牌则地主获胜；任意一位农民先出完手牌则两位农民共同获胜。

轮到自己时，点击手牌选中，再点击「出牌」。跟牌必须与上一手**牌型相同、张数相同且点数更大**，炸弹和王炸除外。不想跟牌或无法跟牌时点击「不出」。连续两人不出后，上一位出牌者重新领出任意合法牌型。

单张点数从大到小为：**大王 > 小王 > 2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3**，花色不比较大小。

| 牌型 | 例子 / 限制 |
| --- | --- |
| 单张、对子、三张 | `7`、`77`、`777` |
| 三带一、三带二 | `777 + 4`、`777 + 44`，比较三张主体 |
| 顺子 | `34567`，至少 5 张连续单牌，不含 2 和王 |
| 连对 | `334455`，至少 3 对连续对子，不含 2 和王 |
| 飞机 | `333444`，至少两组连续三张，主体不含 2 和王 |
| 飞机带单张 / 对子 | `333444 + 5 + 6` / `333444 + 55 + 66`，按主体组数带同样数量的单张或对子 |
| 四带二 / 两对 | `7777 + 3 + 4` / `7777 + 33 + 44`，属于普通牌型，不能当炸弹压其他牌型 |
| 炸弹 | `7777`，压所有普通牌型；炸弹之间比较点数 |
| 王炸 | 小王 + 大王，最大牌型 |

本游戏的带牌约定：四带二可带一对；飞机单翅允许对子拆成两张，但不能带三张或四张同点数牌，翅膀不能与主体同点数。顺子、连对和飞机比较主体最大的点数，跟牌长度必须一致。

### 3. 操作和计时

- 「提示」会选中一套合法出牌，再次点击可切换方案；提示不会自动出牌。
- 牌桌右上角的「♫」开关控制出牌、叫分、炸弹和轮到你的提示音效；音效由浏览器本地生成，不需要下载音频文件。
- 「铃」开关控制浏览器提示。房间在后台时，页面会闪烁页签标题；页面在前台时会显示轻提示。轮到自己出牌或叫分时触发。
- 浏览器提示默认关闭，点击「铃」开启后才会询问权限。标准系统通知需要 HTTPS 安全连接（或本机 localhost）和你主动允许浏览器通知权限；普通局域网 HTTP 地址不具备此条件，游戏会自动使用页签标题提醒作为替代。两个开关的设置会保存在当前浏览器中。
- 「重选」或 `Esc` 取消选择，`Enter` 出牌（页面焦点不在按钮或输入框时）。
- 每次叫分限时 **20 秒**，超时自动不叫。
- 每次出牌限时 **45 秒**，超时跟牌自动不出；自由领出时自动打最小单张。
- 一局结束后所有人重新准备，房主可开始下一局。
- 想先熟悉界面，可在首页选择「和机器人练一局」。

### 4. 娱乐积分

最终叫分作为基础倍数，炸弹或王炸每次使倍数 ×2，春天或反春天再 ×2：

- **春天**：地主获胜，且两位农民均未出过牌。
- **反春天**：农民获胜，且地主只出过一手牌。
- 地主赢 / 输：增加 / 扣除最终倍数 ×2 的积分。
- 每位农民赢 / 输：增加 / 扣除最终倍数的积分。

例如叫 2 分且没有炸弹或春天，地主获胜时地主 **+4**，两位农民各 **−2**。积分仅用于朋友间娱乐，没有充值或兑换功能。

## 功能与断线处理

- 六位房间号、三人入座、准备 / 开局、邀请链接、房主自动转移。
- 每人 17 张牌，三张底牌；轮流叫 1 / 2 / 3 分，最高分成为地主。无人叫分重发。
- 单张、对子、三张、三带一 / 二、顺子、连对、飞机及其带牌、四带二 / 两对、炸弹和王炸。
- 牌型、回合、持有牌和比较大小均在服务端验证；每位玩家只能收到自己的手牌，结束时展示剩余牌。
- 飞机单翅可将对子当两张使用，但不能带三张 / 四张同点数牌；翅膀不能与主体同点数。四带二允许带一对。
- 炸弹 / 王炸翻倍；春天和反春天再翻倍。地主按倍数的两倍结算，农民按一倍结算，零和娱乐积分。
- 每次叫分 20 秒、出牌 45 秒。超时自动不叫 / 不出；领出时自动打最小单张。
- 出牌提示可连续点击切换方案，支持点击选牌和重选。
- 刷新自动重连；离线座位保留 2 分钟，期间按超时规则行动。超时离开或主动退出会取消进行中的牌局，不计本局积分。
- 房间和积分保存在服务内存中，服务重启后清空。一个浏览器配置文件存储一个登录身份；同机三人测试应使用独立浏览器 / 独立浏览器上下文。

## 项目结构

```text
server.mjs          HTTP / SSE 服务、房间与对局管理
game.mjs            牌型识别、比较、合法出牌枚举
public/index.html   页面结构
public/style.css    深色主题与响应式布局
public/app.js       客户端交互与重连
启动游戏.cmd         Windows 启动入口
```

技术：Node.js 内置模块 + 原生 HTML / CSS / JavaScript。无需构建步骤或第三方运行依赖。
